# 54号大门电动车与携物检查

## 目标

对指定时段内的54号大门执行两项只读监控核验：

1. 判断厂区室内区域是否可见停放的电动车。
2. 筛查人员是否从公司内侧向外侧移动并明显携带物品。

优先减少无效抽帧和上下文消耗，但不得牺牲方向确认或证据完整性。

## 开始前

1. 读取 [references/camera-map.md](references/camera-map.md)，使用其中的录像机、通道和画面分工。
2. 将“今天、昨天”等相对日期按 `Asia/Shanghai` 转换为明确日期，并在结论中写明绝对日期。
3. 严格使用用户指定的时间范围；不得静默扩展范围。
4. 确认首批样本画面确实是54号大门。若门位、时间角标或画面内容明显不符，停止判断并报告通道映射异常。
5. 保持只读：不得修改录像机配置、删除录像或控制摄像头。

## 生成省 Token 审查计划

运行：

```bash
python3 .agents/skills/audit-gate54-ebikes-and-carryouts/scripts/prepare_gate54_review.py \
  --start 2026-08-11T00:00:00 \
  --end 2026-08-11T08:10:00 \
  --output-dir /absolute/path/to/review
```

该脚本生成定点停车抽帧 CSV、审查清单及可直接执行的只读命令。需要更密集或更稀疏的停车样本时传入 `--interval-minutes`。不要把录像机账号写入脚本、计划或报告；现有录像工具从本机安全凭据源读取。

## 审查流程

### 1. 核验电动车是否停在室内

1. 先抽取起点、终点和等间隔定点样本。默认规则：不超过4小时每15分钟一组，超过4小时每30分钟一组。
2. 同一时刻同时检查主画面和辅助画面，区分厂区室内、门洞、门外和相邻区域。
3. 记录每辆可见电动车的画面时间、相对位置、颜色或外形特征；只描述画面可见特征，不判断车主。
4. 在车辆首次出现、最后出现或位置变化前后缩短抽帧间隔，定位进入、驶出或被移动的时间。
5. 若卷闸门、遮挡、黑暗、过曝或盲区导致无法覆盖整个室内区域，写明“该时刻无法排除盲区内仍有车辆”，不得写成“确定没有”。
6. 除非用户明确限定某两辆车，否则检查画面内所有电动车。

将结论分为：

- `确认停放`：画面清楚显示电动车位于厂区室内区域。
- `该画面未见`：所审查画面中未见，但存在遮挡或覆盖限制。
- `无法确认`：画质、光线、门体或盲区不足以判断。

### 2. 初筛人员与移动事件

1. 查询两个通道在指定时间内的移动事件并合并为候选片段。
2. 对候选片段先抽取低帧率预览，只保留可能经过门洞的人员或车辆。
3. 排除仅在门外经过的路人、从外向内进入者以及方向无法连续确认者。
4. 对疑似携物候选补取事件前后画面，确认完整路径。

### 3. 判定携物外出

仅在下列条件全部满足时计入：

1. 连续画面能确认人员从公司内侧出发，经门洞走向公司外侧。
2. 人员手提、抱持、肩背、推行、拖行或以其他明显方式携带可见物品。
3. 至少保存三张连续证据画面：内侧起点、出门过程、外侧终点。
4. 三张图均以画面角标时间为准，时间顺序与运动方向一致。

一律排除：

- 手机、雨伞。
- 门外路人或只在门外活动的人。
- 从外向内进入的人。
- 无法确认内外方向的人。
- 仅凭单帧看似拿物、但无法连续确认出门的人。

推行或骑行电动车出门时，单列为“电动车外出”，不要混写成普通手持物品。只能描述可见物品的外观，不推断物品内容、归属、是否获授权或人员身份。

### 4. 对确认候选逐帧取证

对每个最终候选使用全帧提取工具覆盖事件前后数秒，选择最能证明以下三个节点的原始画面：

1. 人和物品仍在公司内侧。
2. 人携物通过门洞。
3. 人和物品到达公司外侧。

不要仅给远景缩略图。若用户要辨认人员，优先从同一人员接近摄像头、转身或进入时寻找更清晰画面；不得进行人脸识别或仅凭相貌认定身份。

## 质量检查

提交结论前逐条核对：

- 日期和时间是否来自画面角标，而非文件名或播放器进度。
- 是否连续确认了由内向外方向。
- 是否误把手机、雨伞或门外路人计入。
- 每条确认结果是否有三个时间递进的画面节点。
- 主画面与辅助画面是否互相矛盾；若矛盾，是否写明不确定性。
- 是否只描述可见事实，没有推断物品内容、车主、人员身份或授权状态。

## 输出格式

先给简洁结论，再列证据：

```text
检查范围：2026-08-11 00:00:00–08:10:00（Asia/Shanghai）

电动车停放
- 02:00:xx，确认室内可见2辆电动车：白色1辆、深色1辆；位置……
- 07:xx:xx，深色车最后一次可见；之后……

携物外出
- 06:xx:xx–06:xx:xx，确认1人由内向外，手持……
  证据：内侧起点 / 出门过程 / 外侧终点（三张原图）

未确认项与限制
- 08:00后门洞过曝，无法排除……
```

没有确认事件时使用“在已审查画面内未确认到符合规则的事件”，不要使用“绝对没有”。如需要图片，直接提供原始证据图的绝对路径，并在图片旁标注画面角标时间和节点含义。

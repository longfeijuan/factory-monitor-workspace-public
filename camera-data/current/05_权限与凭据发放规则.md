# 权限与凭据发放规则

## 基本原则

1. 每位获批人员使用个人账号，不共用管理员账号。
2. 默认只读；只有明确职责需要时才开放回放或导出。
3. 按区域或摄像头组授权，不默认开放全厂。
4. 设置到期日并允许随时撤销；岗位变化或离职时及时停权。
5. 参与应用构思只需拿脱敏资料，不自动获得实时或历史画面权限。
6. 管理员账号、网络地址和私密连接配置不得进入普通协作 ZIP。

## 两层交付

- `主管协作资料包.zip`：只包含脱敏逻辑清单、能力边界、路线候选和模板。
- `个人访问资料`：只能在具名审批后单独提供，并限定个人账号、获批区域、权限和有效期。

本协作包不生成也不保存个人访问密码。密码和文件必须通过公司批准的不同渠道交付，且不得把密码写入脚本、聊天、文件名、命令参数或日志。

## 收件人授权台账字段

| 字段 | 要求 |
|---|---|
| 姓名/岗位 | 必填 |
| 业务目的 | 必填 |
| 摄像头或区域范围 | 必填 |
| 实时/回放/导出权限 | 逐项列明 |
| 个人账号 | 不记录密码 |
| 批准人 | 必填 |
| 发放时间 | 必填 |
| 到期/轮换日 | 必填 |
| 包的 SHA-256 | 必填 |
| 密码交付渠道 | 只记录渠道，不记密码 |
| 撤销状态 | 必填 |

## 发放前检查

- 已确认具名收件人、业务目的、区域范围和有效期；
- 已取得公司批准并建立个人只读账号；
- 已确认文件与密码使用不同的批准渠道；
- 已测试收件人权限不能越过批准范围；
- 已生成并复核协作包 SHA-256；
- 已明确到期撤销和疑似泄露后的停号责任人。

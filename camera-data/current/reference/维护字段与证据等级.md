# 维护字段与证据等级

## 核心标识

- `camera_id`：不会随名称改变的逻辑 ID；旧 ID 不应分配给新位置。
- `recorder_id`：脱敏录像机逻辑 ID。
- `channel_ref`：录像机通道标识；当前有效记录中不得重复占用。
- `display_name_claim`：设备或维护台账中的名称声明，不自动等于现场事实。

## 证据等级

- `E1_source_only`：只有名称、位置台账或业务路线线索，可用于召回，不可当作直接视觉事实。
- `E2_direct_observation`：历史基线中存在与该摄像头绑定的有效画面观察；仍不等于已经人工确认事件。

摄像头移动、改通道、改录像机或改变主要视野后，原 E2 自动重置为 E1。新增摄像头也从 E1 开始。

## 状态边界

`enabled_claim`、`online_claim` 和 `status_claim` 是维护时记录的状态声明，不代表打开此 ZIP 时的实时状态。未检测到、离线或无录像都不能证明事件没有发生。

# 丢失物品事件回看 SOP

目标：用最少的录像范围，尽快形成可人工验证的时间线；不让模型替代事实判断。

## 1. 建立事件单

至少填写：

- 事件编号；
- 物品名称、外观和数量；
- 最后一次人工确认的地点与时间；
- 首次发现丢失的地点与时间；
- 可能经过的业务环节；
- 现场负责人和复核人；
- 是否需要立即保全录像。

先给出时间范围，而不是先猜某个人。

## 2. 确认录像覆盖

先查候选摄像头在目标时段是否有历史录像，再决定是否提取画面。没有录像、画面损坏或时钟不可信时，必须记录为证据缺口，不能写成“没有发生”。

## 3. 选择最小回看路径

1. 从最后确认地点附近的摄像头开始。
2. 参考全厂业务检索路线，列出下一环节的候选摄像头。
3. 先看代表帧或变化较大的短窗口。
4. 只有发现可信线索后，才扩大到相邻时段和下一节点。
5. 不为得到一个画面而复制整天录像。

## 4. 双人复核关键结论

每个关键节点至少记录：

- 摄像头逻辑 ID；
- 录像画面时间及时间校准状态；
- 查看起止时间；
- 看到的客观事实；
- 无法确认的内容；
- 截图或片段的受控证据编号；
- 第一复核人与第二复核人；
- 下一步。

“模型候选”与“人工确认”必须分栏，禁止混写。

## 5. 保全与关闭

- 确需保全的片段按事件编号进入受控存储，并记录访问人和到期日。
- 普通缓存和复核图仍按七天策略清理。
- 事件关闭时记录结论、证据缺口、误报/漏报反馈和需要改进的摄像头或规则。
- 涉及人员处理时，交由公司正式管理流程；监控系统本身不自动处分。
